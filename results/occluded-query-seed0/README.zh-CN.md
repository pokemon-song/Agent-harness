# A/B 遮挡返回记忆消融，第 0 号种子

2026 年 11 月 18 日，直接阅读组和按需问答组从同一个 A 停靠状态实时返回 B。去程复用了历史 H2 的实际动作，交接时距蓝球 A 中心 1.162 米。已核对两组的去程轨迹、返程首帧、起始观测、六篇记忆和代码指纹。每组采用独立的新规划上下文，两组都使用官方 DeepSeek，首次场景物体碰撞即终止。

问答组首个问题同时询问 B 的位置和去程路线。记忆 Agent 回答“部分支持”，从共同文档中选出三条证据，包括起点处实测 B 的可见表面约在里程计坐标 (1.735, 0.742) 米。两组最后连续两次规划请求的输出均达到 8,192 tokens，上游用量将这些输出全部计为推理，harness 没有得到可执行工具调用。直接阅读组在第 42、43 次请求终止，问答组在第 6、7 次规划请求终止。两组均未触及总请求或碰撞上限。本轮只测试了一个配对样本，两组完成进度不同，总 token 数不能推出完成相同任务所需的费用。

交接首帧中两组的实时候选都只有 A。直接阅读组在第 2 次规划请求已读取 B 文件，到第 42、43 次请求时，公开 RGB-D 观测重新出现了 B 的绿色候选。问答组从历史记录取到了 B 的位置，结束之前还没有重新看到 B。
