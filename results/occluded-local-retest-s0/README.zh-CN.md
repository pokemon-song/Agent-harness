# A/B 遮挡返回：按当前位置检索后的复测

2026 年 11 月 21 日使用官方 DeepSeek 的 `deepseek-flash` 测试了同一决策的五对样本，以及从 A 开始的一轮新版返程。实验代码版本为 `6ea66f0`，首次接触场景物体即结束。两项实验合计使用 19 次新 API 请求，用量均有回执。

## 在同一帧只替换记忆答案

还原了历史问答组的第 6 帧（仿真时间 133.20 秒）及前五轮公开观测、工具调用和回执。原进程的内部模型历史没有归档，本次两组均基于同一份公开历史重新请求规划器。当前画面、公开历史、系统提示、工具、原始检索问题、8,192 输出 token 预算全部相同。每一对在相近时间发起，每个样本只请求一次。对每条机器人调用都重新恢复物理状态，执行并检查反馈。

旧答案包含起点 E007、较远路点 E019 和 B 的历史表面点 E006。新版按当前里程计找到了相邻去程点 E022、E021，保留 E006，同时指出记录只覆盖部分路段，缺少柜体边缘和可通行净空的实测值。[两份实际回答](frame6/answers.json) · [共同前视画面](frame6/before.png)

## 从同一 A 停靠点实时返回 B

完整返程使用真实六轮对话历史和新版查询工具，复用原来从出发到 A 的去程物理动作。首次查询取回两个近处路点和 B 的历史观测。随后规划器成功取点两次、转向两次，未发出平移。第 6、7 次规划请求再次用满 8,192 输出 token，停止时离 B 中心 5.081 米，未碰撞、未跌倒。判定距离为 0.82–1.18 米，且须面向 B 停稳、调用 finish。共 7 次规划和 1 次记忆请求，合计 107,571 tokens。
