# 单班路线记忆：到 B 后原路返回

当前 feature 任务使用原第一班 `composite_drawers_gate_b` 场景：起点 → 绕过抽屉柜 → 穿绿门并前进至少 0.8 米 → 距 B 中心约 1 米、面向 B 停稳 → 按去程路线返回起点。此任务没有订单、回执码、干扰订单或额外交班场景。旧六阶段任务及历史结果单独保留。

## 记忆如何参与规划

去程由规划 Agent 使用前视 RGB、几何测量、里程计和运动反馈决定动作。独立记忆 Agent 接收这些公开观测和反馈，自主选择 MD 文件、保存地标、实际绕柜一侧、测得的转折位置、通过门框的经历与不确定性。Harness 只处理事件、证据引用、版本和调用约束，不提取路线答案或生成返程坐标。

到 B 后，先完成去程的独立验收与记忆处理，再关闭去程模型上下文。返程创建新规划上下文，清空短期对话、临时状态和跟踪点；同一机器人后端、姿态、仿真时钟和里程计原点保持不变。两段观测具有相同 `coordinate_frame_id` 与 `mission_start_body_horizontal` 参照，因此 Agent 可以把 MD 中的历史测量与当前位置比较。旧测量仍需结合当前感知复核。

返程仅能读取实际发布的 MD，首次运动和 finish 前要求至少完成一次读取。Agent 自己理解并逆序规划路线，继续逐步调用原有运动工具。程序不自动提供去程轨迹、不按日志倒放动作，也不添加独立任务答案通道。去程未通过或没有可读记忆时，返程标为未运行，不能瞬移到 B 开始测试。

首次读取门控是明确的实验条件；单轮完成、发生了读取或轨迹相似，都不能独立证明记忆带来因果收益。本任务主要观察记忆的实际内容、返程读取、动作选择与空间路线结果，不将其纳入原无记忆模型排行榜。

## 预算

| 指标 | 去程 | 返程 |
| --- | ---: | ---: |
| 墙钟上限，包含模型与记忆等待 | 1,800 秒 | 1,800 秒 |
| 仿真时间上限 | 300 秒 | 300 秒 |
| 规划请求上限 | 60 | 90 |
| 记忆模型请求上限 | 48 | 0（只读） |

相对原第一班的 900 秒／150 秒，单段时间上限翻倍；整趟最多 60 分钟阶段墙钟、198 次模型请求。进程初始化和离线渲染另计。两种模型角色均为 `deepseek-flash`，各保留最近 2 轮历史；单请求 180 秒，输出最多 16,384 tokens。每轮只有一个工具，最大移动向量仍为 0.6 米，不因为时限提高而放宽动作边界。无自动重试整趟任务。

## 独立验收

去程沿用原任务：柜体后方余量、正向穿过门框开口、门后前进 0.8 米、距离 B 约 1 米（容差 0.18 米）、面向 B、停稳，无碰撞和跌倒。

返程以实际去程轨迹为私有评分参考，检查：

1. 从真实 B 停靠位置开始，反向通过同一门框后，再从去程同侧绕过柜体。
2. 返程轨迹保持在实测去程折线 0.50 米内，至少 95% 的去程路线被返程覆盖。按 0.05 米弧长采样，报告最大／平均／P95 偏差、覆盖率和两段路径长度；这不是逐脚印重合。
3. 最终机身 base 回到实际起点 0.30 米内，线速度低于 0.12 m/s、角速度低于 0.25 rad/s；不要求特定终点朝向。
4. 全程累计无碰撞、无跌倒，正确调用 finish 且预算、停止和资源关闭检查通过。无效坐标、倒退时间和缺失穿越证据不能成为通过结果。

完整成绩要求两段都通过。具体真实轨迹、障碍物坐标和评分结果不作为规划观测；公开任务只给验收规则与容差。

## 运行与工件

```bash
MUJOCO_GL=egl .venv/bin/python scripts/run_md_roundtrip.py \
  --api-key-file ../deepseekapi.txt

MUJOCO_GL=egl .venv/bin/python scripts/report_md_roundtrip.py \
  runs/<时间>-md-roundtrip-<ID> --render
```

脚本创建独立目录，冻结 Git、源文件、提示词和预算。`outbound/`、`return/` 保存分别的模型日志、输入图像、评分与新增轨迹；`memory/` 保存实际 MD 和证据；根目录 `trajectory.jsonl` 保存整趟实测轨迹。`turnaround.private.json` 记录 B 处真实状态和切分点，仅供审计；`summary.json` 汇总费用、共享坐标、短期上下文重置和只读完整性检查。失败阶段原样保留。

整趟只建立一个 `third_person/` 录像归档，不插 RESET 卡。后处理从真实控制步状态生成连续仿真时间视频，压缩模型等待，不重新仿真或补画成功动作。报告保留真实墙钟时间、未知请求用量与未执行部分；生成器拒绝覆盖既有报告和录像。

版本在 `feature/async-md-memory-agent` 本地维护，GitHub 推送继续暂停。实现验证和本轮真实运行结果后续追加，不用离线 fixture 结果替代模型成绩。

实现验证：全量 1,173 项通过（28.98 秒）。新检查包含共享坐标下清空规划上下文、按段路径统计、缺少记忆时拒绝运动但允许中止、反向过门／同侧／覆盖验收、保留连续边界、失败清理及 fixture 标记。真实模型试验单独记录。
